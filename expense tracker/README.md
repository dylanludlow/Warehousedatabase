# Expense Tracker

A web application built with Flask that allows users to record and manage income and expenses.

## Features

- Add income
- Add expenses
- View transaction history
- SQLite database
- Simple and responsive interface

## Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- HTML
- CSS

## Installation

Clone the repository:

```bash
git clone https://github.com/dylanludlow/Warehousedatabase.git
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
